WoD20 — V20 Vampire NPC Builder v0.1.8 — Correct derived combat totals

New Builder NPCs now have native WoD20 Attribute totals, soak and initiative calculated after creation. Existing Builder NPCs can be reviewed through the GM Actors sidebar's Audit existing Vampire NPC combat stats link.

The audit previews only proposed derived-value changes; you choose Actors, receive a complete JSON backup, and explicitly confirm before any repair. A separate Restore derived stats control previews the rollback and skips conflicts. No automatic migration occurs. Base ratings, Actors' IDs, Items, notes, existing wounds, artwork and completed rolls are preserved.

Before updating or repairing
- Back up the Foundry world, module folder and separately stored artwork.
- Install the complete ZIP, restart the world and hard-refresh browser clients (Shift+F5).
- Run the audit; confirm the downloaded JSON is saved before repairing selected Actors.

Known limitations
- Foundry v14 / WoD20 7.3.2 live test and two-client workflows pending. No claim of live deployment.
- Actors with active effects are skipped. Unmarked Actors and non-Vampire NPCs are not scanned.
- This version does not alter Combat Workflow's separate detection of PC-type NPCs.
- Reverting module code alone does not undo prior Actor repairs or historical combat.

Rollback: use the restore option with its matching backup before reverting to v0.1.7, or restore a matching world snapshot.
